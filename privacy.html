Music, headphones, diagnostics and online requests

Music notifications/media sessions and Bluetooth/ANC are processed locally after optional Android access. Diagnostics stay local until you choose to share a report. Inspirations fetch a static catalogue from GitHub Pages; the GitHub updater requests release metadata and APKs from GitHub. These services receive normal connection data. In 0.2.5 Google Tasks is temporarily disabled, including sync and cache reads; stored data is retained. See the complete canonical policy for all details.

Muzyka, słuchawki, diagnostyka i połączenia sieciowe

Music i Bluetooth/ANC przetwarzają dane lokalnie po udzieleniu opcjonalnego dostępu Androida. Raport diagnostyczny pozostaje lokalny do wybranego przez Ciebie udostępnienia. Inspirations pobiera wspólny katalog z GitHub Pages, a aktualizator GitHub pobiera informacje o wydaniu i APK. Usługi otrzymują zwykłe dane połączenia. W 0.2.5 Google Tasks jest tymczasowo wyłączone, także synchronizacja i odczyt cache; zapisane dane zachowano. Szczegóły podaje pełna polityka poniżej.
