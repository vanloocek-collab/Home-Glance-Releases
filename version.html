Release

Home Glance 0.2.3

Published September 27, 2026 as a GitHub prerelease. This release combines a visual refresh of the app with layout work aimed at making the widget more reliable on narrow widths.

versionCode 10APK 8,887,955 bytesPublic prerelease
Added

Responsive next alarm

The next-alarm row now degrades progressively instead of clipping: full alarm information when there is enough width, alarm icon only when space becomes limited, and complete hiding only at very small widths.

A standard Android alarm-screen fallback was added for alarm apps that do not provide their own show intent.

Visual

Soft Pixel direction

The main app banner was redesigned in the Soft Pixel style with a weather-first Material You composition and smaller calendar/alarm companion graphics.

The widget weather icon was increased to 22 dp. Alarm and calendar glyphs were redrawn into a cleaner solid monochrome style, and the widget moved to one consistent default icon treatment instead of multiple icon-pack choices.

Settings

Live preview stays with you

The live widget preview was reduced and pinned so it remains visible while browsing appearance settings. This makes background, text and layout changes easier to judge without repeatedly returning to the home screen.

Fixed

Text and narrow-layout reliability

Long-text scrolling was restored after animated icon playback had been disabled. Alarm width calculations were aligned with the real rendered icon size and text weight, preventing the alarm information from being cut off-screen on narrow widgets.

Real devices

Test matrix

The final release was checked on four physical phones:

OnePlus 12POCO X5 ProPOCO X3 NFCMotorola Edge 60 Pro

Motorola Edge 60 Pro was specifically used to verify narrow-widget alarm degradation without clipping. Xiaomi / POCO remains part of the matrix because calendar, alarm-provider and launcher refresh behavior can differ by OEM.

Install

Play Protect and signing notes

POCO / HyperOS may perform an additional Google Play Protect scan when a manually downloaded APK is installed. During testing the scan completed and installation was allowed. The scan itself is treated as normal platform behavior unless Play Protect blocks or flags the APK.

Debug and public release builds use different signing certificates, so a debug installation can require uninstalling before the public release can be installed.

Home Glance 0.2.3

Opublikowane 27 września 2026 jako GitHub prerelease. To wydanie łączy odświeżenie wyglądu aplikacji z pracami nad zachowaniem widżetu na wąskich szerokościach.

versionCode 10APK 8 887 955 bajtówPubliczny prerelease
Dodano

Responsywny najbliższy alarm

Wiersz najbliższego alarmu nie jest już po prostu obcinany. Gdy jest miejsce, pokazuje pełną informację; przy mniejszej szerokości zostaje sama ikona alarmu; dopiero przy bardzo małej szerokości alarm znika całkowicie.

Dodano również standardowe przejście do systemowego ekranu alarmów Androida, gdy aplikacja zegara nie udostępnia własnej akcji otwarcia.

Wygląd

Kierunek Soft Pixel

Główny baner aplikacji został przebudowany w stylu Soft Pixel: pogoda jest motywem dominującym, a kalendarz i alarm pełnią rolę mniejszych elementów towarzyszących w estetyce Material You.

Ikona pogody w widżecie została zwiększona do 22 dp. Ikony alarmu i kalendarza zostały narysowane na nowo w prostszym, pełnym stylu monochromatycznym. Zrezygnowano też z wielu pakietów ikon widżetu na rzecz jednego spójnego wyglądu domyślnego.

Ustawienia

Podgląd LIVE zawsze pod ręką

Podgląd widżetu został zmniejszony i przypięty, dzięki czemu pozostaje widoczny podczas przeglądania ustawień wyglądu. Zmiany tła, tekstu i układu można oceniać bez ciągłego wracania na pulpit.

Naprawiono

Przewijanie tekstu i wąskie widżety

Przywrócono przewijanie długich tekstów po wcześniejszym wyłączeniu odtwarzania animowanych ikon. Obliczanie szerokości alarmu zostało dopasowane do faktycznego rozmiaru ikony i grubości tekstu, dzięki czemu alarm nie jest już obcinany poza krawędzią widżetu.

Urządzenia

Testy na prawdziwych telefonach

Końcowe wydanie zostało sprawdzone na czterech fizycznych urządzeniach:

OnePlus 12POCO X5 ProPOCO X3 NFCMotorola Edge 60 Pro

Motorola Edge 60 Pro posłużyła dodatkowo do testu zwężania widżetu i degradacji alarmu bez obcinania. Xiaomi / POCO pozostają w macierzy testowej ze względu na różnice OEM w kalendarzu, alarmach i odświeżaniu widżetów.

Instalacja

Play Protect i podpis aplikacji

Na POCO / HyperOS podczas ręcznej instalacji APK może pojawić się dodatkowy skan Google Play Protect. W naszych testach skan zakończył się normalnie i instalacja została dopuszczona. Sam skan nie jest traktowany jako błąd aplikacji, o ile Play Protect nie blokuje pliku ani nie zgłasza zagrożenia.

Wersje debug i publiczne wydanie release są podpisane innymi certyfikatami, dlatego instalacja publicznego APK na istniejącą wersję debug może wymagać wcześniejszego odinstalowania debug.
