0.2.4

Release

Home Glance 0.2.4

Published October 4, 2026 as a GitHub prerelease. This release focuses on stability, consistent typography and recovery from real-world Android and network edge cases.

versionCode 11Android 8.0+Public prerelease
Typography

One consistent Pixel-style type system

The previous font-family selector has been removed in favor of one consistent Pixel-inspired family across the app, live preview and widget. Users can choose between Standard and Bold text weights while keeping the existing text-size control.

Old saved font choices migrate automatically. Ticker measurement now follows the same font metrics and weight as the rendered text, improving long-line scrolling consistency across launchers.

Tasks

Google Tasks authorization fixed

Account selection no longer falls through to a false authorization-cancelled state. Successful authorization is preserved and task synchronization can continue normally.

Widget picker

Cleaner public widget entry

The Android widget picker now exposes one public Home Glance widget entry instead of a separate Music widget entry. The picker also shows a real widget preview instead of the application icon.

Polish

Text and localization cleanup

Corrupted characters and localization inconsistencies were corrected, and the typography resources were simplified by removing unused font-specific layouts and bundled font files.

Validation

Real-device release gate

The final 0.2.4 candidate passed automated JVM and targeted instrumentation checks, then passed the four release-blocker retests on both OnePlus 12 and POCO X5 Pro: typography/ticker, Dynamic Rotation, Google Tasks authorization and offline-to-online weather recovery.

Wydanie

Home Glance 0.2.4

Opublikowane 4 października 2026 jako GitHub prerelease. To wydanie skupia się na stabilności, spójnej typografii oraz poprawnym odzyskiwaniu działania po typowych problemach Androida i sieci.

versionCode 11Android 8.0+Publiczny prerelease
Typografia

Jeden spójny styl Pixel

Usunięto wybór rodzin czcionek na rzecz jednej spójnej typografii inspirowanej stylem Pixel w aplikacji, podglądzie LIVE i widżecie. Użytkownik może wybrać wagę Standard lub Pogrubiona, zachowując dotychczasową regulację rozmiaru tekstu.

Stare zapisane wybory fontów są migrowane automatycznie. Pomiar tickera korzysta teraz z tych samych metryk i wagi co renderowany tekst, co poprawia przewijanie długich linii na różnych launcherach.

Zadania

Naprawiona autoryzacja Google Tasks

Wybór konta nie kończy się już fałszywym komunikatem o anulowaniu autoryzacji. Pomyślne połączenie jest zapisywane, a synchronizacja zadań może działać normalnie.

Widżet

Czystszy wybór widżetu w systemie

Systemowy picker pokazuje teraz jeden publiczny wpis Home Glance zamiast osobnego wpisu Music. Podgląd pokazuje rzeczywisty wygląd widżetu zamiast ikony aplikacji.

Dopracowanie

Tekst i lokalizacja

Naprawiono uszkodzone znaki i niespójności lokalizacyjne. Uproszczono także zasoby typografii, usuwając nieużywane warianty layoutów zależne od fontu oraz zbędne pliki czcionek.

Testy

Końcowa bramka wydania

Końcowy kandydat 0.2.4 przeszedł testy JVM i ukierunkowane testy instrumentation, a następnie cztery testy blokujące wydanie na OnePlus 12 i POCO X5 Pro: typografia/ticker, Dynamic Rotation, autoryzacja Google Tasks oraz odzyskanie pogody po powrocie internetu.
