0.2.8

GitHub prerelease · versionCode 15 · Android 8.0+

Home Glance 0.2.8 combines the 0.2.5–0.2.8 improvements in one release: wider Music, consistent navigation, shared content colors and local security fixes.

Music

Long titles pause for about ten seconds before scrolling, after track changes and between loops. Narrow layouts keep both playback times visible.

More room, matching arrows

Music uses more horizontal space without shrinking text or artwork. Side arrows now occupy the same positions on Home, Music and Headphones, including compact Home. Navigation targets are 24×48dp; visible symbols remain 18dp.

Colors and ANC

Automatic, Light and Dark content colors cover all three pages and monochrome icons. Original color artwork is preserved. An outline identifies the known active ANC mode; unknown state selects none.

Local security

Legacy Music opening uses a launcher fallback. Private ANC commands use a non-exported receiver. Corrected logs omit raw Music metadata and Bluetooth MAC addresses.

Google Tasks temporarily disabled

Settings, widgets, synchronization and cache reads remain disabled. Stored data and preferences are retained for possible future restoration.

Verification and limits

336 local JVM checks passed per GitHub/Play variant; three isolated OnePlus layout checks passed. The signed 0.2.8 widget has matching arrow coordinates in Smart Launcher. Full lint retains the known 328-error baseline. API 26–30 hardware, foreign-app ANC attacks, exact launcher timing and POCO remain unverified. See the English release notes for the complete scope.
