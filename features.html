FEATURES

ONLY WHAT EARNS ITS PLACE.

Home Glance is intentionally narrow in scope. Each feature exists to make the home screen more useful.

01

Weather

Automatic or manual location, temperature units and smart refresh.

02

Calendar

Selected calendars, event location, countdowns, ongoing events and filters.

03

Next alarm

The next system alarm adapts to available widget width.

04

Appearance

No background, Material You or Liquid Glass, plus text and layout options.

05

Live preview

See appearance changes before returning to the home screen.

06

11 languages

Language can follow the system or be selected inside the app.
