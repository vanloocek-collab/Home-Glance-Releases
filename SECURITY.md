# Security policy

Please do not publish security or privacy vulnerabilities as public GitHub issues.

Contact:

vanloocek@gmail.com

Include the affected Home Glance version, device/Android details when relevant, and clear reproduction steps.

Do not send or post:

- passwords,
- signing keys,
- access tokens,
- private calendar contents,
- precise personal location unless absolutely necessary and intentionally shared.

During public testing, security and privacy fixes are prioritized for the latest Home Glance release.
