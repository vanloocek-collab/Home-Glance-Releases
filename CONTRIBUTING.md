# Contributing to Home Glance

Thank you for helping improve Home Glance.

Home Glance is currently in public testing, so feedback from different Android devices, manufacturers and launchers is especially valuable.

## Report a bug

Use the **Bug report** template in GitHub Issues.

Please include, when possible:

- Home Glance version
- Android version
- device manufacturer and model
- launcher
- clear steps to reproduce the problem
- what you expected to happen
- what actually happened
- screenshots or screen recordings for visual problems

You can also open a bug report directly from the app:

**Application → Trouble → Report a bug**

Home Glance pre-fills basic device and app information for you.

If you do not use GitHub, use:

**Application → Trouble → Contact developer**

## Suggest a feature

Use the **Feature request** template in GitHub Issues, or open it directly from:

**Application → Trouble → Request a feature**

Please explain:

- what you would like to add or change
- why it would be useful
- how you imagine it working
- an example or mockup, if helpful

## Test Home Glance

You do not need to test everything.

See the full checklist here:

[Home Glance Testing Checklist](TESTING.md)

Testing on different launchers and manufacturers is especially useful.

## Before opening a new issue

Please check whether a similar issue or feature request already exists.

If it does, add useful information to the existing issue instead of creating a duplicate.

## Privacy and security

Do not include private or sensitive information in public GitHub Issues, screenshots or logs.

See:

- [Home Glance Privacy Policy](PRIVACY.md)
- [Security Policy](SECURITY.md)
- [Support Guide](SUPPORT.md)

## Development direction

[Home Glance Roadmap](ROADMAP.md)

## Project philosophy

Home Glance is inspired by the simplicity of Another Widget and aims to keep useful information available at a glance without turning the home-screen widget into a cluttered dashboard.

Home Glance is an independent project and is not affiliated with Another Widget.
