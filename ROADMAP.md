# Home Glance Roadmap

Home Glance is currently in public testing. This roadmap shows the general direction of the project without promising fixed release dates.

## Now

- Collect feedback from early testers
- Fix compatibility issues reported on different Android devices and launchers
- Improve reliability of weather and calendar updates
- Keep the in-app update flow stable
- Review bug reports and feature requests from GitHub and Reddit
- Polish translations and UI details where needed

## Next

- Improve first-run setup and onboarding
- Make troubleshooting and feedback flows even easier
- Expand testing across more manufacturers, Android versions and launchers
- Continue improving accessibility and localization
- Refine widget appearance options without losing the simple At a Glance style

## Ideas

These are possible directions, not confirmed commitments:

- More appearance presets and widget styles
- Additional weather and calendar customization
- More launcher-specific compatibility improvements
- Better import/export or settings migration options
- More smart contextual information while keeping the widget lightweight

## Project philosophy

Home Glance is inspired by the simplicity of Another Widget and aims to be its modern spiritual successor: useful information at a glance, minimal clutter, strong customization, and active development.

Feature priorities will be influenced by real user feedback and compatibility needs.
