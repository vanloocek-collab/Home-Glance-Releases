# Support

Home Glance is currently in public testing.

## Report a bug

Use GitHub Issues:

https://github.com/vanloocek-collab/Home-Glance-Releases/issues/new/choose

Please include:

- Home Glance version,
- Android version,
- device model,
- launcher/ROM when relevant,
- exact steps to reproduce,
- expected and actual behavior,
- screenshots or logs if useful.

## Request a feature

Use the feature request template in the same issue tracker.

## Contact

If you cannot use GitHub, the app can open a pre-filled email to the developer.

For security/privacy-sensitive reports, see `SECURITY.md`.
