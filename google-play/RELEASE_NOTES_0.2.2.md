# Home Glance v0.2.2 — Google Play release notes

## English

Home Glance v0.2.2 improves compatibility and widget reliability.

- More reliable next-alarm updates on Xiaomi / POCO
- Fixed temporary 00:00 after disabling alarms on HyperOS
- Fixed duplicate ticker text on affected launchers
- Fixed weather and date text clipping
- Improved widget resizing, refresh and Dynamic Weather stability
