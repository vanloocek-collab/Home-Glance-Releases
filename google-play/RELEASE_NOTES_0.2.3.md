# Home Glance v0.2.3 — Google Play release notes

## English

Home Glance v0.2.3 refreshes the interface and improves widget reliability on narrow layouts.

- New Soft Pixel home banner
- Responsive next-alarm layout
- Larger 22 dp weather icon and cleaner alarm/calendar glyphs
- Compact pinned live preview
- Restored long-text scrolling
- Better alarm fitting on narrow widgets

## Polish

Home Glance v0.2.3 odświeża interfejs i poprawia działanie widżetu na wąskich układach.

- Nowy baner główny Soft Pixel
- Responsywny układ najbliższego alarmu
- Większa ikona pogody 22 dp i dopracowane ikony alarmu/kalendarza
- Kompaktowy przypięty podgląd live
- Przywrócone przewijanie długiego tekstu
- Lepsze dopasowanie alarmu na wąskich widżetach
