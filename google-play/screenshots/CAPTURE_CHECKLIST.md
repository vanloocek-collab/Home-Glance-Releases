# Final screenshot capture checklist

The files in `reference/` are working references, not the final EN-US Play Store screenshot set.

For the default EN-US listing:

1. Install the exact `playRelease` build you intend to upload.
2. Set Home Glance language to English (US).
3. Make sure any visible version number matches the uploaded build.
4. Hide personal calendar entries, addresses, notifications and other private data.
5. Capture native device screenshots rather than reconstructing the UI.

Recommended set:
- `01-widget-home-screen.png` — widget on a clean launcher
- `02-home-dashboard.png` — Home Glance dashboard
- `03-appearance-settings.png` — appearance/background options
- `04-weather-settings.png` — weather/location configuration
- `05-calendar-settings.png` — calendar/event configuration
- `06-app-settings.png` — language/version/about if useful

Aim for at least four strong screenshots.
